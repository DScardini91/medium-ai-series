## Capítulos

- **Capítulo 0 — Mapa da mina.** Orientação. Para todos os perfis.
- **Capítulo 1 — Fundamentos.** Léxico, LLM por dentro, anatomia de agent. Entrega: vocabulário.
- **Capítulo 2 — Por dentro da inteligência.** Janela de contexto, agentic system, hooks/skills/memory. Entrega: profundidade técnica.
- **Capítulo 3 — Sistemas multi-agents.** Cinco padrões + Kowalski OS como caso. Entrega: visão de arquitetura.
- **Capítulo 4 — So what: implementando na prática.** Cinco níveis de adoção, custo e dedicação. Destino comum.
